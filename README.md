# bg-generator-of-jndxcshiyan
Background image generator for Jinan University City Experimental High School. Creates school-themed backgrounds for PPT, posters, banners, and signage. Built with Canvas, supports preview and PNG export. 济南大学城实验高级中学的背景图像生成器。用于生成学校特色的PPT/海报/横幅/提示牌等背景。使用Canvas绘制，可预览和导出PNG。
